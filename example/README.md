# SeekerKit example app  (Milestone 2)

A minimal Seeker dApp that:
1. gates entry with a **Genesis Token** check (real device owners only),
2. resolves the user's **.skr Seeker ID**,
3. charges a one-time **USDC unlock**, and
4. sends an **FCM push**.

Lands as SeekerKit's modules are built. Follow the roadmap in the root README.
